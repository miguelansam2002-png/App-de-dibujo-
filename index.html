Guía rápida de Trazo Técnico

Una herramienta sencilla para construir bocetos y planos 2D de tuberías, soportes y piezas mecánicas.

  1. Elige Tubería, Línea, Rectángulo o Cota, y arrastra sobre el lienzo.
  2. Selecciona una pieza precargada (grapa, codo, brida, válvula, soporte...) y toca el punto en que quieres insertarla.
  3. Con Seleccionar, toca cualquier elemento para moverlo o editar sus coordenadas y tamaños en Propiedades.
  4. Activa o desactiva Ajuste a cuadrícula y usa las unidades mm / cm / m / pulgadas.
  5. Usa Guardar para obtener un archivo editable .json, o Exportar para SVG, PNG e impresión/PDF.

Atajos: Supr para eliminar; Ctrl+Z / Ctrl+Y para deshacer o rehacer; Escape para seleccionar; flechas para mover piezas; rueda del mouse para hacer zoom.

Importante: se conservan automáticamente los cambios en este navegador, siempre que el almacenamiento local esté disponible. También conviene guardar copias .json.
